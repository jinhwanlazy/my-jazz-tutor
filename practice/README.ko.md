# 일일 연습

[English](README.md) · [한국어](README.ko.md)

여기는 실제 연습 영역입니다. 개발은 `../workflow/`에서 진행합니다. 두 영역의 Git
루트는 상위 디렉터리 하나입니다. 아래 명령은 저장소 루트에서 실행합니다.

```sh
test -e practice/profile.json || cp practice/profile.example.json practice/profile.json
uv run --project practice jazz
```

프로필에 실제 경험·목표·시간 선호를 적습니다. 예제 값은 사용자 진술이 아니며
모르는 정보는 비워 둡니다. Codex 코치는 사용자가 쓰는 언어로 대화합니다.

첫 화면은 날짜별 연습 목록입니다. ‘새 연습’을 누르면 Codex가 프로필과 최근 연습,
피드백·메모·스킵 사유를 검토해 맞춤 과제를 만들고 검증 후 목록에 추가합니다.
커리큘럼 과제를 정해진 순서로 밟는 방식이 아닙니다. 항목을 직접 눌러야 연습실에
들어갑니다. 메트로놈과 선택적 반주로 연습하고 ‘연습 완료’를 누르면 저장 후 목록으로
돌아옵니다. 완료 항목에서 😈 불가능 / 💪 도전적이었음 / 🙂 좋은 연습이었음 /
🙄 너무 쉬워서 의미 없었음 중 하나와 선택 메모를 남기거나 수정합니다.

피드백이 없어도 완료입니다. 완료 항목은 기록 상세로 열리고 ‘다시 연습’은 새 항목을
만듭니다. 미완료 항목은 선택 사유와 함께 넘길 수 있습니다. 원래 녹음은 보존합니다.
BPM은 메트로놈 설정이며 실제 타건을 분석한 BPM이 아닙니다. 음·박 자동 판정은 없습니다.
진도나 별도 연습 기록 탭 대신 목록에서 내용·상태·결과·메모·사유를 확인합니다.

생성에는 로컬 Codex 설치, 로그인, 네트워크와 사용 한도가 필요합니다.
`codex login status`로 확인하고 필요하면 `codex login`을 실행하세요. 별도 API_KEY는
필수가 아닙니다. 현재 대화가 자동 공유되는 대신 명시적인 기록 맥락이 Codex로
전달됩니다. 실패하면 오류와 재시도를 표시하고 고정 과제로 대신 채우지 않습니다.

```sh
uv run --project practice jazz status
uv run --project practice jazz recommend
uv run --project practice jazz runtime
```

`recommend`와 `suggest`는 같은 생성·저장 명령입니다. `status`는 읽기만 합니다.
대화형 코칭의 공유 맥락·스키마·저장 명령은 활성 COACH.md와
[개발 문서](../workflow/README.ko.md)를 따릅니다. 과제 조건과 실제 관측, LLM 해석은
구분합니다. 새 과제는 영어 원문으로 저장하고 한국어 화면에서는 Codex 번역본을 만들어
재사용합니다. 제목·설명·방법·코칭 해석이 함께 번역되며 원래 조건과 사용자 메모는
바꾸지 않습니다. 번역 중에는 원문을 표시하고 실패하면 재시도할 수 있습니다.

사이드 메뉴는 Practice(연습)이며 MIDI 연결과 입력 선택이 항상 보입니다. 모바일에서는
상단에 유지합니다. BPM은 시작 전에 선택하고 녹음이 끝날 때까지 잠깁니다. 일시정지
중에도 변경할 수 없으며 다음 녹음을 시작하기 전에 다시 선택할 수 있습니다.

기본 주소는 http://127.0.0.1:8765 입니다. 다른 포트는
`uv run --project practice jazz serve --open --port 8768`로 시작합니다. 설정에서
한국어·영어를 바꿀 수 있습니다. 같은 브라우저·주소·포트로 돌아오면 미전송 MIDI를
복구할 수 있습니다. 라이브 악보는 하나의 연속 시간축이며 원본 입력과 별개입니다.

신뢰하는 LAN에서는 `uv run --project practice jazz serve --host 0.0.0.0 --port 8768`로
시작하고 다른 기기에서 `http://<서버-LAN-IP>:8768`로 접속합니다. 특정 로컬 IPv4 주소로
바인딩할 수도 있습니다. 로그인 기능은 없어 접속 가능한 기기는 기록 접근과 추천 요청이
가능합니다. HTTP에서 생성·메트로놈·저장은 동작하고 MIDI는 HTTPS 또는 localhost가
필요합니다. 자세한 내용은 [LAN 접속 안내](../workflow/README.ko.md#lan-접속)를 참고하세요.

실행 버전은 runtime.json에 고정합니다. 발행 시 새 버전 활성화를 우선하고 호환
미완료 과제는 이어가며 비호환 과제만 사유와 함께 종료합니다. 업데이트 종료는 실패·
스킵·연습 결과가 아닙니다. 새 버전 활성화 후 서버를 재시작합니다.

개인 CSV, 프로필, sessions.sqlite3, .recommendations/, .translations/, 메모, runtime.json은 Git에
포함되지 않습니다. 서버를 중지하고 이 파일들을 별도 개인 백업에 보관하세요.
.runtime/ 캐시는 Git으로 재생성할 수 있지만 개인 기록은 Git이 복원하지 않습니다.
