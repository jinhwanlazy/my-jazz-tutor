# My Jazz Tutor

[English](README.md) · [한국어](README.ko.md)

Codex 로그인으로 쓰는 로컬 재즈 피아노 코치입니다. 대화형 코칭과 웹의 ‘새 연습’이
같은 프로필·실제 기록·난이도 피드백·메모·스킵 사유를 검토해 다음 연습을 구성합니다.
기존 커리큘럼은 참고 자료이며 고정 후보 목록이나 필수 진도표가 아닙니다.

하나의 Git 저장소 안에서 [practice](practice/README.ko.md)는 실제 연습,
[workflow](workflow/README.ko.md)는 코칭·소프트웨어 개발 영역입니다. 각 영역의
AGENTS.md를 먼저 읽습니다. 개인 자료는 로컬에 보관하고 Git에 넣지 않습니다.

```sh
test -e practice/profile.json || cp practice/profile.example.json practice/profile.json
uv run --project practice jazz
```

웹의 첫 화면은 날짜별 연습 목록입니다. 생성 진행 상태를 표시하고 검증된 항목을
추가하되 자동 진입하지 않습니다. 항목을 직접 열어 연습한 뒤 ‘연습 완료’로 저장하고
목록으로 돌아옵니다. 완료 항목에서 네 가지 난이도 라벨과 선택 메모를 입력·수정합니다.
다시 연습은 별도 항목이며 넘기기 사유도 선택입니다. 기록·진도 탭을 별도로 두지 않습니다.

Codex CLI 설치·로그인·네트워크·사용 가능 한도가 필요하며 별도 API_KEY는 필수가
아닙니다. `codex login status`로 확인합니다. 기록을 요청마다 명시적으로 전달하고
기존 대화를 자동 공유하지 않습니다. 앱이 과제와 악보 데이터를 검증해 저장합니다.
연결·로그인·한도·시간 초과·검증 실패는 오류로 표시하며 고정 과제로 대체하지 않습니다.

메트로놈·선택적 반주·연속 악보·MIDI 원본 저장을 제공합니다. 자동 BPM은 메트로놈
설정값이며 분석된 실제 연주 BPM이 아닙니다. 음악적 MIDI 자동 채점은 아직 없습니다.
설정에서 영어·한국어 UI를 바꾸며 원문과 진행 중 입력을 유지합니다.

새 발행 버전 활성화를 우선합니다. 호환 과제는 원래 조건을 유지하고 비호환 과제는
사유와 함께 종료하되 원문·MIDI를 보존합니다. 소스 편집 자체는 활성화가 아닙니다.
runtime.json이 활성 커밋을 고정하고 .runtime/은 재생성 가능한 캐시입니다.
개인 CSV·프로필·MIDI·추천 맥락/결과·메모는 Git에서 제외하므로 별도로 백업합니다.
